# Roadmap

## 현재 단계
데이터 관리 + 라벨링 UI 고도화 + UI/UX 디자인 리뉴얼

## 완료된 기능
- 프로젝트/데이터 스토어 CRUD
- 이미지 업로드 및 폴더 관리
- 파일 트리 뷰, 가상화 스크롤, 키보드 네비게이션
- 태스크 생성 및 데이터 풀 연동
- QuickLook 미리보기
- 스냅샷 버전 관리
- Konva 기반 라벨링 인터페이스
- UI/UX 디자인 리뉴얼 (테마, 인터랙션, 브랜딩, 시각 위계)
- 키보드 매니저 중앙화 (useKeyboardManager)
- Task/Pool 모드 시각적 강화
- ARIA 접근성 기초 적용

## 단기 우선순위
- 라벨링 UX 개선 (어노테이션 유형 확장, 편의기능)
- AI Worker 학습 파이프라인 구현 (YOLO 학습/추론)
- 모델 관리 및 배포 기능

## 중장기 방향
- S3 등 클라우드 스토리지 지원
- 팀 협업 기능 (다중 사용자, 권한 관리)
- 자동 라벨링 (AI-assisted labeling)
- 실시간 학습 모니터링 대시보드
- 사이드바 네비게이션 (phase 2로 보류 중)
