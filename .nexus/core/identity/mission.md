# Mission

Vision Flow는 Vision AI 모델의 학습/추론 파이프라인을 웹 기반으로 통합 관리하는 서비스입니다.

## 해결하는 문제
- 이미지 데이터 수집·관리·라벨링·학습이 분산된 도구에 흩어져 있어 파이프라인 전체를 일관되게 관리하기 어려움
- 비개발자도 Vision AI 모델을 구축·운영할 수 있는 접근성 있는 도구가 부족

## 목표
- 데이터 업로드 → 라벨링 → 학습 → 추론까지 단일 웹 인터페이스에서 완결
- 프로젝트 단위로 데이터·태스크·모델을 체계적으로 관리
- YOLO 계열 모델 중심의 Object Detection, Instance Segmentation, Pose Estimation 지원
